Implementiere ein neues Feature im Projekt.

Vorgehen:

1. Analysiere die Feature-Beschreibung: $ARGUMENTS
2. Identifiziere betroffene Module oder Features im Repository.
3. Lies die minimal relevanten Dateien, um bestehende Patterns zu verstehen.
4. Plane kurz die Implementierung.
5. Implementiere das Feature mit möglichst kleinen Änderungen.

Regeln:

- Respektiere die bestehende Architektur.
- Bevorzuge Erweiterungen bestehender Module statt neue Strukturen.
- Füge keine unnötigen Dependencies hinzu.
- Vermeide große Refactors.

Antwortstruktur:

1. Kurze Beschreibung des Plans
2. Umsetzungsschritte
3. Geänderte Dateien
4. Kurze Zusammenfassung des Features
