Führe ein strukturiertes Code Review durch.

Ziel:

- Qualität sichern
- Risiken erkennen
- Architekturverletzungen finden

Vorgehen:

1. Analysiere die angegebene Datei oder den Bereich: $ARGUMENTS
2. Lies relevante Dateien im Kontext.
3. Prüfe folgende Aspekte:

Codequalität
- Lesbarkeit
- Struktur
- Komplexität

Architektur
- Einhaltung der Modulgrenzen
- Abhängigkeiten
- Layer-Trennung

Fehlerquellen
- Edge Cases
- mögliche Bugs
- Performanceprobleme

Verbesserungen
- konkrete Verbesserungsvorschläge
- kleine Refactors

Antwortstruktur:

1. Überblick
2. Gefundene Probleme
3. Verbesserungsvorschläge
4. Architekturhinweise
