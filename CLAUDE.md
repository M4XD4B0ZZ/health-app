# CLAUDE.md

This repository's governance is defined in [`SSOK.md`](SSOK.md) and
[`AGENTS.md`](AGENTS.md) — read both before making changes. They are tool-neutral and
binding for every agent/tool used on this repo (see AGENTS.md's "Tool Adapter Principle"),
including Claude Code. Task planning and status live in [`ROADMAP.md`](ROADMAP.md);
verification requirements live in [`VERIFY.md`](VERIFY.md).

Do not add Claude-specific rules here that duplicate or diverge from `AGENTS.md` — extend
`AGENTS.md` instead, so every agent working on this repo stays governed by the same rules.
